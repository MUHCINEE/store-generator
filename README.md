# Maison Verde

A mobile-first small-shop storefront and protected owner dashboard built with React, Vite, Express, and SQLite.

- Public storefront: `/`, `/storefront`, or `/store/<STORE_SLUG>`
- Owner sign-in: `/login`
- Product management: `/admin`

For installation, environment configuration, local use, and production guidance, see [HOW_TO_USE_ME.md](./HOW_TO_USE_ME.md).
