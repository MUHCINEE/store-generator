# Maison Verde

A mobile-first small-shop storefront and Firebase-backed owner dashboard built with React, Vite, Firebase Authentication, and Cloud Firestore.

- Public storefront: `/`, `/storefront`, or `/store/<STORE_SLUG>`
- Owner sign-in: `/login`
- Product management: `/admin`

Configure Firebase Authentication and Firestore, then follow [HOW_TO_USE_ME.md](./HOW_TO_USE_ME.md) for setup and deployment.
