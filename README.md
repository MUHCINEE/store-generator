# Maison Verde

A mobile-first small-shop storefront and owner dashboard built with React, Vite, Express, and MySQL.

- Public storefront: `/`, `/storefront`, or `/store/<STORE_SLUG>`
- Owner sign-in: `/login`
- Product management: `/admin`

Configure a local MySQL database, then follow [HOW_TO_USE_ME.md](./HOW_TO_USE_ME.md) for setup and use.
